# DIP-5: Requirements Specification

## Functional Requirements
- FR-1: User selects Area of Interest (AOI) and date range.
- FR-2: System fetches pre- and post-event Sentinel-1 images.
- FR-3: Perform speckle filtering, thresholding, and generate flood polygon layers.

## Non-Functional Requirements
- NFR-1: Processing time < 60 seconds per image tile.
- NFR-2: High availability for emergency monitoring.
