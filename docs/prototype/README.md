# Interactive UX Mockup

Open [`index.html`](index.html) in a browser. This standalone page is the
interactive mockup described in the [UX prototype document](../08_ux_prototype.md).
The user scenarios, interaction flow, proposed API contract, limitations, and
acceptance checklist are documented there.

The map and result values are illustrative placeholders only. The page does
not run geospatial processing and must not be used for emergency decisions.
