# DIP-1: Project Proposal

## Executive Summary
Developing SAR Flood Mapping Platform for rapid inundation mapping.

## Problem Statement
Traditional optical imagery is hindered by cloud cover during extreme weather. Sentinel-1 SAR imagery enables all-weather flood monitoring.

## Objectives & Scope
- Automated pipeline for Sentinel-1 GRD ingestion.
- Change detection and Otsu/NDR thresholding.
- Interactive visualization dashboard.
